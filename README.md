# CNKI PDF Batch Assistant (Chrome Extension)

一个面向 CNKI（知网）页面的批量 PDF 下载助手。支持从检索结果页快速收集文献、批量获取 PDF 链接、批量下载、失败恢复与日志追踪，并按“期刊/年份/文件名”自动归档。

## 功能概览

- 在知网检索页为每条文献注入 `+` 收藏按钮。
- 一键“添加本页”，将当前页文献批量加入侧边栏列表。
- 批量获取 PDF 下载链接（支持“重新获取链接”覆盖旧链接）。
- 批量下载并自动跟踪下载状态（下载中/成功/失败）。
- 自动按 `期刊/年份/文件名.pdf` 归档保存下载文件。
- 下载失败时尝试静默恢复（后台打开详情页并自动点击 PDF 下载）。
- 识别验证页与“操作频繁需重登”场景，分别给出恢复策略。
- 每篇论文支持手动重试、单条删除、复制文献信息。
- 内置错误日志面板，支持复制全部日志与清空。

## 适用环境

- 浏览器：Chrome（Manifest V3 扩展）
- 页面：CNKI 相关检索/详情页面（含部分 WebVPN 场景）
- 系统：Windows / macOS / Linux

## 安装方式（开发者模式）

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目根目录。
5. 扩展加载后，点击扩展图标即可打开侧边栏。

## 快速使用

1. 登录知网账号，并打开检索结果页。
2. 在侧边栏点击“添加本页”收集当前页文献。
3. 点击“获取链接”（或“重新获取链接”）补全 PDF 链接。
4. 勾选要下载的条目，点击“下载”。
5. 成功下载的条目会从列表移除。

## 下载与归档规则

- 下载由页面上下文触发（更接近手动点击下载）。
- 后台会在下载前注册元信息，并在 `onDeterminingFilename` 阶段改写保存路径。
- 文件名会进行非法字符清洗，避免 Windows 命名失败。
- 目录结构示例：

```text
当代法学/2026/某某论文.pdf
```

## 失败恢复策略

- 主下载超时后：
  1. 静默打开详情页。
  2. 自动定位并点击 PDF 下载按钮（多选择器兜底）。
  3. 若成功则继续后续任务。
- 若识别到验证页：
  - 提示人工完成验证，并等待该篇下载完成后继续。
- 若识别到重登页（例如“操作太过频繁，请退出后重新登录”）：
  - 停止本轮批量，需手动登录后再重启批量。
- 失败重试保护：
  - 单篇有失败重试上限（代码当前为 2 次），达到上限后停止自动重试。

## 页面按钮说明

- 添加本页：把当前结果页文献加入列表。
- 获取链接：为尚未有 PDF 链接的条目补全链接。
- 重新获取链接：强制刷新已有条目的链接。
- 下载：批量下载已勾选条目。
- 清空：清空整个列表。
- 删除（单条）：移除该论文。
- 重试（单条）：重置该条失败计数并重试。

## 项目结构

```text
.
├─ manifest.json              # 扩展清单（权限、入口、内容脚本）
├─ background.js              # Service Worker（网络请求、下载、归档改名）
├─ content/
│  └─ main.js                 # 内容脚本（注入收藏按钮、采集当前页）
├─ sidepanel/
│  ├─ index.html              # 侧边栏页面结构
│  ├─ index.css               # 侧边栏样式
│  └─ index.js                # 侧边栏逻辑（列表、获取链接、下载与恢复）
├─ icons/                     # 扩展图标与二维码资源
├─ ADD.md                     # 增量功能说明
└─ 使用手册.txt                # 中文使用手册
```

## 关键权限说明

`manifest.json` 里使用了以下关键权限：

- `storage`：保存列表、设置、排序状态。
- `downloads`：触发下载与监听下载状态。
- `activeTab` / `scripting`：向当前页注入脚本并执行页面动作。
- `sidePanel`：启用扩展侧边栏。
- `host_permissions: *://*/*`：用于跨域页面访问与兼容多入口页面。
